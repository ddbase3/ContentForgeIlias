# ContentForge ILIAS SCORM Export Target

Version: 0.1.4

`Base3IliasLab\ContentForge\ContentForgeIliasScormExportTarget` integrates generated ContentForge SCORM packages into the ILIAS repository as native SCORM learning modules.

## Technical name

```text
contentforgeiliasscormexporttarget
```

## Responsibility

The target accepts a `ContentForgeExportResult` of type `scorm12_package` and creates an ILIAS SCORM 1.2 learning module in the selected repository container.

This class belongs to `Base3IliasLab`, not to the generic ContentForge plugin, because it depends on ILIAS repository object creation and SCORM object internals.

## Import path

The target follows the same essential steps as the ILIAS SCORM upload workflow:

1. Create `ilObjSCORMLearningModule`.
2. Set title, subtype and description.
3. Create the object and repository reference.
4. Put it into the selected parent tree node.
5. Apply permissions.
6. Mark it offline initially.
7. Create the SCORM data directory.
8. Write the generated SCORM package files into the data directory.
9. Rename executable files via `ilFileUtils::renameExecutables()`.
10. Call `readObject()` so ILIAS parses `imsmanifest.xml`.
11. Apply learning-progress defaults via `setLearningProgressSettingsAtUpload()`.

## Redirect behavior

After successful creation, the delivered export metadata contains:

```text
contentForgeAutoRedirect = true
autoRedirect = true
redirect_url = ilias.php?baseClass=ilSAHSEditGUI&ref_id=<new_ref_id>
```

The UIHook JavaScript reads this metadata from the ContentForge AJAX response and redirects the full browser page.

## Current scope

Only SCORM 1.2 is implemented. SCORM 2004 is intentionally not generated by the current ContentForge SCORM exporter.
